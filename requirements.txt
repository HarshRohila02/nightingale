# Compatible-release pins: `~=X.Y` allows any newer X.* (e.g. pandas~=2.2 accepts
# 2.3); `~=X.Y.Z` allows patch releases only. Either way, the exact installed
# versions are what matter for reproducibility, so after your first successful
# install, freeze an exact lock:
#
#     pip freeze > requirements.lock.txt
#
# and commit it. The lock file is what makes results reproducible months later
# (docs/06-engineering-conventions.md §1).
#
# Clinical NLP is intentionally NOT here — scispacy pins specific spaCy versions
# and model URLs that frequently break the main install. See requirements-nlp.txt
# and install it only when you reach the free-text intake work (Phase 3).
